### Projects
- **[Induction Heads in GPT-2](https://github.com/AlexanderYWHDu/Induction_Head)** — Identified and verified induction head circuits in GPT-2 small using TransformerLens (attention pattern analysis, ablation, activation patching), following Elhage et al. and Olsson et al.
- **[Dialogue Divergence Tree](https://github.com/AlexanderYWHDu/dialogue-divergence-tree)** - A web app for tree-structured AI conversation exploration. Ask a question, AI generates 4 divergent angles with full responses, pick one, and repeat — building a tree of ideas. You can also ask follow-up questions at any point for linear deep-dives. Built for HackWashU 2026.
- **[Vibe Coding Assistant](https://github.com/AlexanderYWHDu/Vibe-Coding-Assistant)** - A web app that guides users through a structured 5-stage process to turn vague project ideas into detailed, actionable spec documents — all powered by Google's Gemini AI. Built for the Google AI Hackathon.
